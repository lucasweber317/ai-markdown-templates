# Feedback Channels

The sources the agent scans on every synthesis. Fill this in for your setup and update it as channels emerge. Channels connected to Claude (via MCP or built-in tools) are scanned directly; everything else arrives as exports dropped into `feedback-sources/`.

---

## Channels

| Channel | Where / how to access | Cadence | Notes |
|---|---|---|---|
| <Ticket system> | e.g. project key, board URL, or export | Continuous | Customer-driven tickets |
| <Business-review notes> | e.g. wiki parent page or folder | Quarterly | Structured Customer Success input — often the highest-signal source |
| <Chat channels> | e.g. channel names to search | Continuous | List the specific channels; scope searches by the brief's date range |
| <Customer emails> | e.g. escalation mailbox or search terms | Continuous | Escalations and review follow-ups |
| <Surveys / NPS> | export location | Per campaign | Drop exports into `feedback-sources/` |
| <Community forum> | URL | Continuous | Public asks and complaints |

## Source priority

When channels disagree or time is limited, scan in this order (highest signal first): structured review notes → active-ticket queue → chat channels → email → surveys → local files. Adjust to your setup.
