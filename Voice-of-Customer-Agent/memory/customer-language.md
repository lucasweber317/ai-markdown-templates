# Customer Language

Verbatim phrasing customers use to describe problems and needs. Keeps downstream writing (epics, roadmap communication, enablement) grounded in the customer's own words instead of internal vocabulary.

## Format

```
### [Topic]
- "Verbatim quote" — Customer (source, date)
```

**Example entries (fictional):**

### Onboarding
- *"Getting new users productive is our biggest drag right now."* — Northwind (interview, 2026-01-15)
- *"New teams stall for weeks before they see value."* — Contoso (interview, 2026-01-18)

---

## How to Use This File

- The agent appends notable quotes here after each synthesis, grouped by topic.
- Quotes are verbatim — never cleaned up, including typos (mark them [sic] if needed).
- Cull topics that stop appearing; this is a working vocabulary, not an archive.
